# BioGuider benchmark runbook

Quick-reference for running the multi-file stress benchmark and reading its output.

## One-liner launch

```
scripts/bench_launch.sh                          # runs test_multi_file_full_matrix
scripts/bench_launch.sh test_single_file_stress  # runs a smaller single-file test
```

`bench_launch.sh` unsets stale shell env vars, probes the LiteLLM proxy, and fails fast
if the key or URL is broken. It then `tee`s the run to `logs/multi_file_stress_<ts>.log`
and writes the log path to `/tmp/bench_log.txt`.

## Watch progress

```
scripts/bench_status.sh                          # one-liner snapshot
tail -f $(cat /tmp/bench_log.txt)                # live log
```

`bench_status.sh` shows: run dir, files done / 10, count of LLM 200 OKs, pytest alive,
error count, and age of the run in minutes.

## Summarise results

```
poetry run python scripts/bench_wake_summary.py outputs/multi_file_stress/run_<ts>
```

Renders missing fig1-6 on any file subdir that has STRESS_TEST_RESULTS.json; writes
WAKE_SUMMARY.md at the run root with per-file and per-model F1 tables, moat hit counts,
and figure inventory. Idempotent — safe to re-run mid-benchmark.

## Output layout

```
outputs/multi_file_stress/run_<ts>/
├── INDEX.md                         # top-level map (written at completion)
├── WAKE_SUMMARY.md                  # quick briefing (regenerated by bench_wake_summary.py)
├── <vignette>/
│   ├── <vignette>.original.Rmd
│   ├── <vignette>.level_<N>.corrupted.Rmd
│   ├── <vignette>.level_<N>.manifest.json
│   ├── <vignette>.level_<N>.<model>_bioguider.fixed.Rmd
│   ├── STRESS_TEST_RESULTS.json     # per-level / per-model metrics
│   ├── STRESS_TEST_TABLE.csv        # flat CSV of same
│   ├── STRESS_TEST_CATEGORY_DETAIL.csv
│   ├── STRESS_TEST_REPORT.md
│   └── fig1_f1_by_error_level.{png,pdf}   ← +5 more figs (fig2..fig6)
└── _aggregate/
    ├── AGGREGATE_RESULTS.json       # pooled across all 10 files
    ├── AGGREGATE_TABLE.csv
    └── fig1..fig6.{png,pdf}
```

## Env gotcha — stale shell OPENAI_API_KEY

`conftest.py` calls `load_dotenv()` without `override=True`, so any shell variable named
`OPENAI_API_KEY` beats what's in `.env`. If the benchmark logs show 401s from the proxy
with `Received API Key = sk-...<prefix-that-is-not-your-.env-key>`, the shell has a
stale var. Fix: `unset OPENAI_API_KEY` before launching (bench_launch.sh does this).

## Switching between benchmark mode and full evaluation

- Benchmark mode (LiteLLM proxy): `OPENAI_BASE_URL` set, `OPENAI_API_TYPE` absent,
  `OPENAI_API_KEY=sk-...<bioguider-virtual-key>`.
- Full evaluation (Azure, with embeddings): uncomment `OPENAI_API_TYPE=azure`, swap
  `OPENAI_API_KEY` to the Azure key, comment out `OPENAI_BASE_URL`.

See `.env` header cheat-sheet at the bottom of the file.
